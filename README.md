#  Furniro Landing Page

Furniro is a furniture landing page built with HTML and CSS, featuring a clean and modern interface with lightweight jQuery-based interactions.

The project focuses on translating a modern furniture website design into a structured frontend layout.

##  Live Demo

https://shanajtech.github.io/Furniro-Landing-Page/

##  Features

- Modern furniture landing page design
- Clean and organized user interface
- Multiple website sections
- Product-focused content layout
- Lightweight jQuery interactions
- Structured CSS styling

##  Technologies Used

- HTML5
- CSS3
- jQuery

##  Project Purpose

This project demonstrates my ability to build landing pages from a given design and convert visual layouts into structured HTML and CSS.

It also showcases attention to layout, spacing, typography, and frontend presentation.

##  Run Locally

Clone the repository:

```bash
git clone https://github.com/shanajtech/Furniro-Landing-Page.git
```

Go to the project directory:

```bash
cd Furniro-Landing-Page
```

Open `index.html` in your browser.
